# Build a Premium Arabic Restaurant Menu Website

Create a complete, responsive, single-page scrolling website for a restaurant specializing in fresh poultry, ready-to-cook products, charcoal grills, and special-occasion meals.

The website should function as a digital restaurant menu, not a traditional e-commerce store. Customers should be able to scroll through all menu sections, view realistic food photographs, check prices, and contact the restaurant directly.

Use the attached restaurant logo as provided, without modifying it. Use the attached reference image as visual inspiration.

## 1. Visual Identity and Design

- Create a luxurious black theme inspired by premium restaurant menus.
- Use a subtle black wood-textured background.
- Use elegant white or warm ivory Arabic typography, with restrained gold accents.
- Use high-quality, realistic food photography with dramatic lighting and professional food styling.
- Arrange food photographs artistically, mixing large plates, close-up shots, and elegant editorial layouts.
- Avoid generic e-commerce product grids, cartoon illustrations, artificial-looking food, and excessive decorations.
- Keep the layout sophisticated, spacious, and easy to read.
- Use a clear Arabic font with proper right-to-left (RTL) support.
- Add subtle scroll animations and smooth transitions without affecting performance.
- Keep the same visual identity throughout the entire website.

## 2. Header and Navigation

Create a clean, responsive header containing:
- The restaurant logo.
- A “Menu” navigation link that scrolls to the menu sections.
- A “Contact Us” link that scrolls to the contact section.

Use a sticky header if it improves usability. Ensure the mobile navigation is simple and easy to use.

## 12. User Experience and Responsiveness

- Keep all website content in Arabic.
- Implement proper RTL layout throughout.
- Make the website fully responsive on mobile, tablet, and desktop.
- Optimize images for fast loading.
- Ensure menu item names and prices remain readable on small screens.
- Use different photographs appropriate to each product.
- Avoid repeating the same photograph across unrelated products.
- Add smooth scrolling between sections.
- Ensure all navigation and contact buttons work correctly.
- Use accessible color contrast and appropriately sized touch targets.
- Do not add a shopping cart, checkout, online payment, or ordering system.
- Do not add a backend or admin dashboard for this initial version.

Build the actual working frontend, not just a static mockup.

## Final Deliverable

Preserve every product, price, and contact number exactly as provided. Prioritize Arabic text accuracy, usability, and a consistent premium design.
